---

## 📂 Estructura del Proyecto

El repositorio está organizado por ejercicios, comenzando desde los conceptos más fundamentales.

### 🔹 Ejercicio 0: Introducción a Vue (Root)
*Ubicación: `./`*

Esta es la primera toma de contacto con la instancia de Vue y el data binding.
- **Archivos:** `index.html`, `apps.js`, `styles.css`
- **Funcionalidad:**
  - Creación de una aplicación Vue básica.
  - Renderizado declarativo de datos.
  - Ejemplo de cambio dinámico entre una "Lista de tareas" y una "Lista de compras".

### 🔹 Ejercicio 1: Perfil Interactivo "Sobre Mí"
*Ubicación: `./exercise01/`*

Una página de perfil personal que explora más características de la reactividad.
- **Archivos:** `index2.html`, `apps2.js`, `styles2.css`
- **Funcionalidad:**
  - Interpolación de texto para datos personales (Nombre, Apellido, Edad).
  - **Métodos:** Función para calcular edad futura (`sumarEdad`).
  - **Eventos/Reactividad:** Generación de números aleatorios dinámicos.
  - **Data Binding en atributos:** Enlace dinámico a una URL externa (WikiDex).

---

## 🛠️ Cómo ejecutar los ejercicios

Dado que estos son ejercicios introductorios que utilizan Vue a través de CDN, no es necesario instalar dependencias de Node.js por el momento.

1.  Clona o descarga este repositorio.
2.  Navega a la carpeta del ejercicio que desees ver.
3.  Abre el archivo `.html` (`index.html` o `index2.html`) directamente en tu navegador web de preferencia (Chrome, Firefox, Edge, etc.).

¡Así de simple! 🎉
